## Формулы 6 сценариев IRRBB (по 8-МР Банка России)

### Обозначения:
- `БС(k)` — базовая ставка для тенора k
- `СКС` — шок краткосрочной ставки (для RUB = 5.00%)
- `СДС` — шок долгосрочной ставки (для RUB = 3.00%)
- `T` — срок до середины интервала в годах (из Таблицы 1)
- `t = 4` (константа)

### Сценарии:

**1. Параллельный сдвиг вверх**
`РС = БС + 4.00%`

**2. Параллельный сдвиг вниз**
`РС = БС - 4.00%`

**3. Увеличение наклона (короткие вниз, длинные вверх)**
`РС = БС - 0.65 * СКС * e^(-T/t) + 0.9 * СДС * (1 - e^(-T/t))`

**4. Уменьшение наклона (короткие вверх, длинные вниз)**
`РС = БС + 0.8 * СКС * e^(-T/t) - 0.6 * СДС * (1 - e^(-T/t))`

**5. Увеличение краткосрочных ставок**
`РС = БС + СКС * e^(-T/t)`

**6. Снижение краткосрочных ставок**
`РС = БС - СКС * e^(-T/t)`
