# Расчёт базовой и стрессовых кривых доходности ОФЗ

## Описание

Электронная таблица для расчёта базовой кривой доходности и шести стрессовых
сценариев IRRBB (8-МР Банка России) на основе данных MOEX на 2026-07-31.
Все расчёты выполнены формулами Excel, параметры сценариев вынесены в отдельные ячейки.

Файлы:
- `IRRBB_Stress_Curves_new.xlsx` - расчёт;
- `curve_scenario_1.png` ... `curve_scenario_6.png` - графики «базовая кривая и сценарий»
  (1 - сдвиг вверх, 2 - сдвиг вниз, 3 - увеличение наклона, 4 - уменьшение наклона,
  5 - рост коротких ставок, 6 - снижение коротких ставок);
- `curve_all_scenarios.png` - сводный график всех сценариев.

## Структура таблицы

**Лист MOEX** - исходные точки кривой MOEX: срок (лет) и доходность (%), от 0,25 до 20 лет.

**Лист базовая** - 19 временных интервалов таблицы 1 приложения к 8-МР.

| Столбец | Содержание |
|---|---|
| A | Номер интервала |
| B | Интервал ЦБ |
| C | Тенор (1d, 1m, 3m ... 30y) |
| D | Тенор в годах (по нему определяется базовая ставка) |
| E | T - срок до середины интервала, лет (по нему считаются стрессы) |
| F-I | Нижняя и верхняя точки MOEX и их ставки |
| J | Базовая ставка БС, % |
| K | Метод определения БС |
| L-Q | Шесть сценариев |
| S-T | Параметры сценариев для рубля |

## Расчёт базовой ставки

Базовая ставка БС определяется для тенора (столбец D):

- тенор есть на MOEX - берётся значение MOEX без изменений («Значение MOEX»);
- тенор короче первой точки MOEX - берётся ближайшее значение («Ближайшее значение»);
- тенор между двумя точками MOEX - линейная интерполяция («Интерполяция»):
  БС = D + (T - C) / (E - C) * (F - D), где C и D - нижний срок и ставка MOEX,
  E и F - верхний срок и ставка MOEX;
- тенор длиннее последней точки MOEX - линейная экстраполяция по двум последним
  точкам («Экстраполяция»): БС = y_n + (y_n - y_(n-1)) / (x_n - x_(n-1)) * (T - x_n).

В столбце K метод подсвечен: зелёный - ближайшее значение, синий - интерполяция,
оранжевый - экстраполяция.

## Параметры сценариев (рубль, таблица 3 8-МР)

| Параметр | Значение |
|---|---|
| ΔПар | 4 |
| СКС | 5 |
| СДС | 3 |
| t | 4 |

## Сценарии (T - срок до середины интервала, столбец E)

1. Параллельное повышение: БС + ΔПар
2. Параллельное снижение: БС - ΔПар
3. Увеличение наклона: БС - 0.65 * СКС * exp(-T/t) + 0.9 * СДС * (1 - exp(-T/t))
4. Уменьшение наклона: БС + 0.8 * СКС * exp(-T/t) - 0.6 * СДС * (1 - exp(-T/t))
5. Рост коротких ставок: БС + СКС * exp(-T/t)
6. Снижение коротких ставок: БС - СКС * exp(-T/t)

## Проверка

- формулы сценариев пересчитаны независимо для всех 19 интервалов, расхождений нет;
- при подстановке данных из примера заказчика таблица воспроизводит его базовые ставки и стрессовые значения
  (например, 9,47 / 9,53 / 9,71 для сценария «увеличение наклона» на первых трёх интервалах).
