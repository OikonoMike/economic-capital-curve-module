
Расчёт базовой и стрессовых кривых доходности ОФЗ

Описание

В рамках первого спринта проекта реализована электронная таблица для
расчёта базовой кривой доходности и стрессовых сценариев на основе
исходных данных MOEX.

Расчёты выполнены в LibreOffice Calc введу отсутствия версии Microsoft Excel для Ubuntu

Структура таблицы

Лист MOEX

Содержит 12 исходных точек кривой MOEX на 2026-07-31 (сроки от 0,25 до 30
лет): Срок, лет - срок до погашения; Доходность, % - соответствующая
доходность.

Данные расположены по возрастанию срока до погашения.

Лист Базовая

Содержит 19 временных интервалов T, базовую ставку и результаты
расчёта стрессовых сценариев.

Столбец   Содержание

Расчёт базовой ставки

Для каждого срока T определяется базовая ставка БС по исходным
точкам MOEX.

Если срок находится между двумя исходными точками, используется линейная
интерполяция:

БС = D + ((T - C) / (E - C)) * (F - D)

где:  T - требуемый срок; C и D - нижний срок и
соответствующая ему ставка MOEX; E и F - верхний срок и
соответствующая ему ставка MOEX.

Если T меньше минимального срока MOEX или больше максимального срока,
используется ближайшая крайняя ставка. Таким образом, за пределами
диапазона исходных данных применяется метод ближайшего значения, а не
экстраполяция.

Для текущих данных: три первых срока (T = 0,0028; 0,0417; 0,1667) короче
минимального срока MOEX (0,25), поэтому для них берётся ближайшее значение
13,59 %; остальные 16 сроков (в том числе T = 25 между 20 и 30 годами)
получены линейной интерполяцией. Способ определения ставки указан в
столбце H, он подсвечен цветом: зелёный - ближайшее значение, синий -
интерполяция, оранжевый - экстраполяция. В служебных столбцах E и F для
сроков короче минимального стоит прочерк.

Параметры стрессовых сценариев

Параметры вынесены в отдельные ячейки листа Базовая:

Параметр     Значение

ΔПар              4
СКС               5
СДС               3
t                 4

Параметры используются в формулах сценариев через абсолютные ссылки на
ячейки, чтобы адреса параметров не менялись при копировании формул по
строкам.

Стрессовые сценарии

1. Параллельное повышение
   БС_up = BC + ΔПар

2. Параллельное снижение
   БС_down = BC - ΔПар

3. Увеличение наклона
   БС_steep = BC - 0.65 * СКС * exp(-T/t) + 0.9 * СДС * (1 - exp(-T/t))

4. Уменьшение наклона
   БС_flat = BC + 0.8 * СКС * exp(-T/t) - 0.6 * СДС * (1 - exp(-T/t))

5. Рост коротких ставок
   БС_short_up = BC + СКС * exp(-T/t)

6. Снижение коротких ставок
   БС_short_down = BC - СКС * exp(-T/t)

Проверка расчётов

Выполнены следующие проверки: - исходные сроки MOEX расположены по
возрастанию; - базовые ставки для сроков, совпадающих с точками MOEX,
соответствуют исходным доходностям; - ставки на сроках T = 0,0028; 0,0417;
0,1667 равны 13,59 % (ближайшее значение), на T = 25 равна 16,025 %
(интерполяция между 20 и 30 годами); - параллельные сценарии отличаются
от базовой ставки на ΔПар; - формулы остальных сценариев используют
заданные параметры и срок T; - формулы рассчитаны для всех 19
интервалов.

Для проверки интерполяции можно временно использовать промежуточный
срок, например T = 1,5 года. В таком случае ставка должна рассчитываться
между точками MOEX 1 и 2 года (13,63 и 14,58 %), то есть быть равной
14,105 %. После проверки тестовую строку следует удалить, чтобы сохранить
исходный набор из 19 интервалов.

Результат

Подготовлена таблица LibreOffice Calc с исходными данными MOEX, базовой
кривой, параметрами и шестью стрессовыми сценариями. Расчётные формулы
позволяют пересчитывать результаты при изменении исходных ставок или
параметров сценариев.
