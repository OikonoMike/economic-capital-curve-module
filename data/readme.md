# Данные

Здесь хранятся выгрузки кривых доходности.

## Файлы
- `gcurve_2026-07-31_moex.csv` — сырые данные с Мосбиржи (12 теноров, от 0,25 до 30 лет).
- `gcurve_2026-07-31.csv` / `.xlsx` — базовая кривая на 19 теноров по методике ЦБ РФ (8-МР), результат `src/interpolate_curve.py`.
  Колонки: тенор, тенор в годах, T (середина интервала), ставка, метод (значение MOEX / ближайшее значение / интерполяция / экстраполяция)
  и флаги `интерполировано`, `экстраполировано`.

## Источник
Московская Биржа (MOEX), КБД ОФЗ. Дата среза: 2026-07-31.
