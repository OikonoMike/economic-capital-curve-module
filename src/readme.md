# Исходный код

Python-скрипты для обработки данных.

## Основные скрипты
- `interpolate_curve.py` — **активный скрипт**. Строит базовую кривую на 19 теноров ЦБ РФ по точкам MOEX (до 20 лет):
  значение MOEX берётся как есть, для коротких теноров — ближайшее значение, между точками — линейная интерполяция,
  для 30 лет — экстраполяция. Логика совпадает с листом «базовая» в `excel/IRRBB_Stress_Curves_new.xlsx`.
  - Зависимости: `pandas`, `numpy`, `openpyxl`.
  - Запуск: `python src/interpolate_curve.py`


### `calendar_checker.py` — календарь торгов

Скрипт отвечает за проверку того, проводятся ли торги в конкретную дату, и определяет логику «догрузки» данных, если запуск был пропущен.

* **Основа:** Логика опирается на полный производственный календарь РФ (с учетом переносов праздников и рабочих суббот) на 2026–2027 годы.
* **Источник данных:** `data/calendar_2026-2027.csv`.
* **Функции:**
  * `is_trading_day(date)` — возвращает `True`, если дата является рабочим днем, и `False`, если это выходной или праздник.
  * `get_previous_trading_day(date)` — возвращает предыдущий рабочий день (используется для логики догрузки данных за прошедшие периоды).
* **Зависимости:** `pandas`, `datetime`, `os`.
