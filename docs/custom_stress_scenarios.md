# Пользовательские стресс-сценарии

На странице кривых пользователь может создать свой непараллельный
стресс-сценарий. Для этого он задаёт сдвиг ставки отдельно по нужным
бакетам. Бакет — интервал сроков, которому соответствует одна
расчётная точка кривой.

## 1. Действия пользователя

1. Выбрать отчётную дату.
2. Нажать отдельную кнопку «Добавить сценарий».
3. Ввести сдвиги для нужных бакетов. Форма показывает все 19 бакетов
   в порядке сроков.
4. Нажать «Рассчитать». На графике появятся базовая и пользовательская
   кривые за выбранную дату.
5. При повторном расчёте пользовательская линия обновляется. При смене
   отчётной даты результат предыдущего расчёта убирается с графика.

## 2. Правила расчёта

- За основу берём сохранённую базовую кривую за выбранную дату.
- Сдвиги вводятся в процентных пунктах. Значение `+2` повышает ставку
  на 2 п.п., значение `−0,5` снижает её на 0,5 п.п.
- Пустое поле или `0` оставляет ставку бакета без изменения. Для расчёта
  требуется хотя бы один ненулевой сдвиг.
- Форма принимает дробные значения с точкой или запятой. В API она
  передаёт их числами, например `-0.5`.
- Итоговая ставка каждого бакета равна его базовой ставке плюс заданный
  сдвиг. Каждый сдвиг применяется к одному бакету.

В первой версии результат доступен для просмотра на сайте. Сохранение
сценариев, их выгрузка и передача в аналитику команды 3 требуют отдельного
согласования.

## 3. Формат API

`POST /api/v1/curves/custom-scenario`

Форма передаёт отчётную дату и введённые сдвиги. Для бакетов используются
существующие коды сроков, например `3m` и `10y`.

```json
{
  "report_date": "2026-11-20",
  "shifts": [
    {"tenor_label": "3m", "shift_pp": 2},
    {"tenor_label": "10y", "shift_pp": -0.5}
  ]
}
```

В ответе API возвращает `report_date` и массив `points` из 19 точек
в порядке сроков. Поля каждой точки:

| Поле | Описание |
|---|---|
| `tenor_label` | Код бакета, например `3m` |
| `tenor_years` | Срок в годах |
| `base_rate_pct` | Базовая ставка в процентах |
| `shift_pp` | Применённый сдвиг в процентных пунктах |
| `rate_pct` | Итоговая ставка в процентах |

Ошибки:

- `404` — за выбранную дату нет сохранённой базовой кривой.
- `422` — неверный формат входных данных, неизвестный или повторяющийся
  бакет, некорректное число либо отсутствие ненулевых сдвигов.

Сообщение об ошибке должно содержать причину, которую можно показать
пользователю. При ошибке форма сохраняет введённые значения для исправления.

## 4. Контрольный пример

Используем базовую кривую за 20.11.2026 и сдвиги из примера запроса.

| Бакет | Базовая ставка | Сдвиг | Ожидаемая ставка |
|---|---:|---:|---:|
| `3m` | 13,5384% | +2 п.п. | 15,5384% |
| `1y` | 14,1835% | Поле пустое | 14,1835% |
| `10y` | 17,0535% | −0,5 п.п. | 16,5535% |

Ожидаемый результат — 19 точек, из которых меняются только `3m` и `10y`.
На графике пользовательская кривая выше базовой на сроке 3 месяца,
ниже на сроке 10 лет и совпадает с ней на остальных сроках.
